# potato-disease-classification-cnn


## Overview

This project uses a Convolutional Neural Network (CNN) to classify potato leaf images into three categories:

* Potato Early Blight
* Potato Late Blight
* Healthy Potato Leaf

## Technologies Used

* Python
* TensorFlow
* Keras
* Google Colab
* NumPy
* Matplotlib

## Workflow

1. Load dataset from Google Drive
2. Split data into training and validation sets
3. Build CNN architecture
4. Train the model
5. Evaluate model performance
6. Predict disease from new leaf images
7. Save trained model

## Classes

* Potato___Early_blight
* Potato___Late_blight
* Potato___healthy

## Results

The CNN model successfully classifies potato leaf diseases and can predict the class of unseen images.
